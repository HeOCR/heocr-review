HeOCR Review

HeOCR Review הוא אתר קטן שבו מתנדבים בודקים הצעות לתיקון טקסט עברי מול סריקות של דפים מודפסים. ההחלטות משמשות את HeOCR, פרויקט קוד פתוח לזיהוי תווים (OCR) בעברית, כדי לתקן טקסטי ייחוס ולמדוד את איכות הזיהוי.

המשימה הראשונה: בדיקת טקסט ייחוס מוויקיטקסט מול הסריקה. סוכן תוכנה הציע תיקונים; רק החלטה של אדם משנה טקסט.

האתר מופעל על ידי פרויקט הקוד הפתוח HeOCR. יצירת קשר: heocrproject@gmail.com. הקוד ב-GitHub: HeOCR/heocr-review.

About

HeOCR Review is a small website where volunteers check proposed corrections of Hebrew text against scans of printed pages. The decisions are used by HeOCR, an open-source Hebrew OCR project, to correct reference texts and measure recognition quality.

The first task checks Hebrew Wikisource reference text against the scan. A software agent proposed the corrections; only a human decision changes any text.

It is run by the HeOCR open-source project. Contact: heocrproject@gmail.com. Source code: github.com/HeOCR/heocr-review (MIT).
